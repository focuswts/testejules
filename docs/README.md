# Survival Sandbox Prototype

This is the prototype for a multiplayer survival sandbox game conceptually inspired by Project Zomboid and Space Engineers, built with Babylon.js and Colyseus.

## Requirements

- Node.js
- pnpm

## Getting Started

1. Install dependencies:

   ```bash
   pnpm install
   ```

2. Run tests:

   ```bash
   pnpm test
   ```

3. Build everything:

   ```bash
   pnpm build
   ```

4. Run development environment (starts client and server):
   ```bash
   pnpm dev
   ```
